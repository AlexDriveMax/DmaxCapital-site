# DMax Capital LLC Website

Commercial real estate investment firm specializing in value-add acquisitions.

## 🚀 Quick Start

### Option 1: Netlify (Easiest)
1. Drag and drop this folder to [netlify.com/drop](https://app.netlify.com/drop)
2. Site will be live in seconds

### Option 2: Cloudflare Pages
1. Push to GitHub
2. Connect to Cloudflare Pages
3. Build settings: None needed (static HTML)
4. Deploy!

### Option 3: GitHub Pages
1. Push to GitHub repository
2. Settings → Pages → Deploy from `main` branch
3. Select `/` (root) folder
